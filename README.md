## Результат

Развёрнуты две настоящие VirtualBox VM: сервер Zabbix и пользовательский АРМ. Оба хоста добавлены через веб-интерфейс, имеют шаблон **Linux by Zabbix agent**, зелёную доступность агента и свежие Latest data. Ping в обе стороны: 4/4, без потерь. Сервер и классические агенты: Zabbix 7.0.32; СУБД PostgreSQL 17; Nginx и PHP-FPM 8.4.

Стенд использует сохранённую инфраструктуру ЛР4: внешняя Debian 13.7 VM на Windows и вложенная Debian 13.7 VM. Мониторинг идёт по изолированному Bridge-сегменту 172.27.25.1 ↔ 172.27.25.2. NAT используется для доступа к пакетным репозиториям. Имена VirtualBox VM сохранены от ЛР4; гостевые hostname изменены для ЛР5. Полная схема, версия обоих VirtualBox, ресурсы и оговорки приведены в PDF.
